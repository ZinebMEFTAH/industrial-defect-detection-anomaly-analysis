# Contributions

| Contributor | Main responsibilities | Status |
|---|---|---|
| Member A | Classical baseline, preprocessing, unsupervised methods | To assign |
| Member B | YOLO/supervised methods, demo interface | To assign |
| Both | Dataset protocol, evaluation, threshold analysis, report, presentation | Shared |

## Collaboration rules
- Create a feature branch for substantial changes.
- Use descriptive commit messages.
- Open a pull request before merging shared work.
- Record experiment settings and results in `results/experiments.csv`.
